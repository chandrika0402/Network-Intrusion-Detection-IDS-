# Network-Intrusion-Detection-IDS-
# Modelling Intrusion Detection: Analysis of a Feature Selection Mechanism

## Project Overview

This project focuses on developing a Machine Learning-based Intrusion Detection System (IDS) using the **NSL-KDD dataset**. It aims to analyse and verify the feature selection mechanism proposed by Nkiama, Said and Saidu (2016) in their research paper, *A Subset Feature Elimination Mechanism for Intrusion Detection System*.

The project evaluates the effectiveness of different classification algorithms in detecting network intrusions and investigates how feature selection influences classification performance.

## Objectives

- Develop a Machine Learning-based Network Intrusion Detection System.
- Analyse the NSL-KDD dataset for network attack detection.
- Implement and evaluate Decision Tree and Random Forest classifiers.
- Examine the impact of feature selection on intrusion detection performance.
- Compare classification results and assess the effectiveness of the proposed feature elimination mechanism.
- Verify the findings presented in the referenced research paper.

## Dataset

**NSL-KDD Dataset**

The NSL-KDD dataset is a benchmark dataset widely used for evaluating Network Intrusion Detection Systems.

It contains network traffic records representing:
- Normal network connections.
- Denial of Service (DoS) attacks.
- Probe attacks.
- Remote-to-Local (R2L) attacks.
- User-to-Root (U2R) attacks.

Dataset resource: https://www.unb.ca/cic/datasets/nsl.html
